ADR 0001: Record architecture decisions
Status: Accepted
Date: 2025-09-11
Context
We will store architecture decisions as ADRs.

Decision
Use ADR markdown format in docs/decisions/ADRs. Each significant decision gets a numbered file, e.g. 0001-xyz.md.

Consequences
All significant tech choices (DB, MQ, frameworks, deployment, security) must have an ADR.
Decisions become traceable and reviewable over time.
